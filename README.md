# team-blue/php-exception

PHP Exception library providing a base exception hierarchy with JSON schema support for team.blue PHP applications.

It ships a Symfony bundle (`ExceptionBundle`), typed HTTP exceptions (`HttpException`), attributes for metadata extraction, and a `DefaultJsonSchemaException`. Works together with [`team-blue/php-json-immutable-objects`](https://github.com/teamdotblue/php-json-immutable-objects) and [`team-blue/php-util`](https://github.com/teamdotblue/php-util).

## Installation

```bash
composer require team-blue/php-exception
```
